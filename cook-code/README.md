# Code & Cook

Game memasak dengan visual programming (blok kode ala Scratch).

## Menjalankan
1. Buka folder ini di VS Code.
2. Pasang ekstensi **Live Server** (Ritwick Dey).
3. Klik kanan `index.html` → **Open with Live Server**.

Alternatif tanpa ekstensi: jalankan `python -m http.server 5500` di folder ini,
lalu buka http://localhost:5500.

> Project memakai ES Modules, sehingga TIDAK bisa dibuka dengan double-click
> (file://). Harus lewat server lokal.
